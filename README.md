# Publier le site SAE S1.04 sur GitHub Pages

Compte GitHub **à toi** (pas celui de Simon).

1. Crée un dépôt public, par exemple `sae-s104-kdou`.
2. Dézippe `sae-s104-pages.zip` à la racine du dépôt (les `.html`, `style.css` et `images/` doivent être à la racine, pas dans un sous-dossier).
3. Sur GitHub : **Settings → Pages → Branch : `main` / folder : `/ (root)` → Save**.
4. Le lien sera : `https://TON-PSEUDO.github.io/sae-s104-kdou/`

Sans Git en ligne de commande : sur github.com, **Add file → Upload files**, glisse tout le contenu du zip, puis active Pages comme ci-dessus.
